Версия 1.0.17: добавлена полная поддержка управления подпунктами (полями) внутри блока «Контактна особа». Поддержаны все типы системных и кастомных полей (email, телефон, Telegram, Discord, Instagram, имя/фамилия, теги, roistat, utm и любые дополнительные поля) независимо от того, какие атрибуты разметки использует Pipedrive (`fields-list-row`, `field-row`, `field-label`, `data-field-key` и др.). Улучшено глубокое сканирование: расширен поиск виртуальных и прокручиваемых контейнеров на странице.

Версия 1.0.16: принудительное сканирование проходит по виртуализированному списку внутри «Контактна особа», собирает поля на каждой позиции и возвращает страницу к исходной прокрутке. Это устраняет ситуацию, когда в поп‑ап попадало только первое видимое поле, например «Мітки». Глубокая прокрутка выполняется только по кнопке «Сканировать страницу»; фоновая проверка страницу не прокручивает. Во время прохода используется существующий лоудер.

Версия 1.0.15: громкость всех звуков уменьшена на 25% — до 75% от прежнего уровня.

Версия 1.0.14: поддерживается глобальная группа `data-testid="person-block"`. В поп‑апе она отображается под названием из заголовка Pipedrive — например «Контактна особа». Можно скрыть весь блок или отдельные именованные поля внутри него. Строка с аватаром и именем без подписи не создаёт отдельный переключатель; она скрывается вместе со всей группой. Настройки применяются после обновления Pipedrive, как и для остальных групп.

Версия 1.0.13: видимость фиксируется один раз для загруженного документа. Переключение, импорт и фоновое сканирование сохраняют настройки, но не перестраивают открытую страницу. Новые настройки применяются после полной перезагрузки Pipedrive. Браузер инжектирует content.css на стадии document_start, а скрипт назначает скрывающие маркеры из снимка настроек, полученного при запуске страницы. Это устраняет повторное скрытие и раскрытие блоков из-за изменений хранилища во время работы.

Версия 1.0.12: при ручном сканировании поверх поп‑апа показывается предоставленная анимация catLoader.gif.mp4 и подпись «Ищу новые группы и поля…». Видео воспроизводится без звука, зацикливается и скрывается после результата или ошибки. Чтобы анимация не промелькнула незаметно при быстром ответе, она показывается минимум 650 мс.

## Chrome

1. Распакуйте архив.
2. Откройте `chrome://extensions` и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение», выберите папку `extension`.
4. Обновите открытую страницу Pipedrive. Закрепите расширение на панели.
5. Откройте карточку, раскройте группы и прокрутите список полей.
6. Нажмите значок расширения. Зелёный переключатель означает «показывать».

Нажатие на название группы раскрывает список полей. Переключатель справа скрывает всю группу. Переключатели внутри скрывают отдельные строки, сохраняя заголовок группы. Выключение группы сохраняет настройки её полей.

Названия считываются автоматически только из уже загруженных элементов страницы. Для первого обнаружения некоторых полей нужно раскрыть группу или прокрутить карточку. Исчезнувшие со страницы названия остаются в каталоге. Новые поля по умолчанию видимы.

Версия 1.0.2: при первом посещении аккаунта названия собираются сразу и во время первой минуты загрузки. При последующих загрузках сохранённый список используется сразу, а поиск новых названий начинается через минуту и повторяется раз в минуту. Сохранённые настройки видимости применяются немедленно, в том числе к динамически появляющимся элементам.

Настройки и названия хранятся в storage.local расширения отдельно для каждого адреса Pipedrive. Значения полей не сохраняются. Настройки Chrome и Safari независимы. Удаление расширения удаляет настройки.

## Safari на Mac

Расширение полностью совместимо с Apple Safari. Его можно запустить двумя способами:

### Способ 1: Прямая загрузка без Xcode (Safari 17+)
1. Откройте **Safari** → **Настройки** (Settings) → вкладка **Дополнения** (Advanced).
2. Включите пункт **«Показывать функции для веб-разработчиков»** (Show features for web developers).
3. Перейдите во вкладку **Разработка** (Developer) в настройках Safari.
4. Нажмите **«Загрузить временное расширение…»** (Add Temporary Extension…) и выберите распакованную папку `extension`.
5. Подтвердите паролем или Touch ID. Значок расширения появится на панели Safari.
6. При клике откроется окно управления полями Pipedrive со стильным гласморфизмом, звуками котика и радужным акцентом.

### Способ 2: Упаковка в приложение через Xcode (для публикации)
Для постоянного распространения через App Store или TestFlight с полным Xcode:
```sh
xcrun safari-web-extension-packager "/полный/путь/pipedrive-fields/extension"
# или в Xcode 14/15:
# xcrun safari-web-extension-converter "/полный/путь/pipedrive-fields/extension"
```

Официальная инструкция Apple: https://developer.apple.com/documentation/safariservices/packaging-a-web-extension-for-safari

## Ограничения

Поддерживаются группы с атрибутом data-testid="fields-list-group" и поля data-testid="fields-list-row", как в предоставленном HTML. При изменении разметки Pipedrive потребуется обновление. Названия служат идентификаторами: одноимённые группы одного аккаунта используют общую настройку, а одноимённые поля разных групп независимы. Переименованный элемент считается новым.

Скрытие влияет только на отображение и не изменяет данные Pipedrive. В версии 1.0.3 отдельные поля полностью убираются из раскладки, а скрытые группы виртуального списка занимают только 1 пиксель: положительная высота нужна для измерителя списка. Обновления посторонних частей страницы не запускают сканирование, а непрерывные изменения больше не откладывают его бесконечно. Поведение прокрутки требует проверки на живой странице.

Хранилище: https://developer.chrome.com/docs/extensions/reference/api/storage
