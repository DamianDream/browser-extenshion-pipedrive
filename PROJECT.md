# Pipedrive Fields — Документация проекта

## 1. Обзор проекта
**Pipedrive Fields** — кроссбраузерное расширение для **Google Chrome** и **Apple Safari** (Manifest V3), предоставляющее удобную боковую панель (Side Panel) в стиле glassmorphism (дизайн-система *mySmart*) для CRM Pipedrive (`*.pipedrive.com`).

Расширение решает две ключевые задачи:
1. **Управление видимостью полей (Экран «Fields»)**: скрытие ненужных групп и отдельных кастомных/системных полей интерфейса сделок Pipedrive без задержек и без скачков скролла виртуализированного списка (React Virtuoso).
2. **История сделок (Экран «History»)**: автоматическое фоновое отслеживание открываемых сделок в Pipedrive, быстрый доступ к недавним просмотрам, закладки избранных сделок, фильтрация по периодам, дедупликация и быстрый поиск.

## 3. Основные компоненты и механизмы

### 3.1. Архитектура экранов (Fields & History)
В шапке расширения расположен анимированный логотип котика (чистый CSS с независимой анимацией монетки, лап и бликов) и заголовок активного экрана.
- По клику на логотип или заголовок открывается глассморфное меню переключения экранов:
  - **«Fields»** (📑) — управление видимостью полей текущей сделки.
  - **«History»** (🕒) — история просмотренных сделок.
- Выбранный экран сохраняется в хранилище (`pf_active_view`).

### 3.2. Экран «Fields» (Управление видимостью)
- **Синхронная защита скролла (React Virtuoso)**: контент-скрипт `content.js` перехватывает DOM-мутации через синхронный `MutationObserver` до фаз Layout/Paint браузера. Скрываемые поля получают класс `.pdf-hidden-field` с жестким сжатием геометрии:
  ```css
  .pdf-hidden-field {
    display: none !important;
    contain: strict !important;
    opacity: 0 !important;
    line-height: 0 !important;
    font-size: 0 !important;
    height: 0 !important;
    min-height: 0 !important;
    margin: 0 !important;
    padding: 0 !important;
  }
  ```
- **Группы и поля**: поддержка всех блоков Pipedrive, включая аккордеоны, кастомные поля, блок «Контактна особа», «Організація», «Докладні дані».
- **Интеллектуальная группировка**:
  - Полностью выключенные группы автоматически опускаются вниз списка и становятся полупрозрачными.
  - При выключении главного тумблера группы все внутренние поля синхронно выключаются.
  - Очистка от технических счетчиков вида `3/3 • 3` через утилиту `cleanLabel`.
- **Звуковое оформление**: щелчки тумблеров сопровождаются синтезированными и натуральными звуками мяуканья (работают только на вкладке Fields, отключаются в настройках).
- **Сброс правил**: двухэтапный безопасный сброс с возможностью мгновенного отката («Повернуть як було?» / «Хай буде так!»).

### 3.3. Экран «History» (История сделок)
- **Автономный трекинг визитов (`content.js`)**:
  - При переходе на URL вида `https://*.pipedrive.com/deal/:id` запись о посещении автоматически сохраняется в `chrome.storage.local`.
  - Отслеживаются как прямые загрузки страниц, так и SPA-переходы (`history.pushState`, `history.replaceState`, `popstate`, MutationObserver на URL).
- **Правило 5 минут**: повторное открытие той же сделки в течение 5 минут не создает дубликат — обновляется время визита (`timestamp: now`), и запись поднимается на первое место.
- **Лимит ротации**: сохраняется до 10 000 сделок (хранилище использует ~1.5 МБ из доступных 10 МБ `storage.local`). При переполнении старые записи автоматически вытесняются.
- **Вкладки All и Favorites**:
  - Вкладка **All** — все записи с живым счетчиком.
  - Вкладка **Favorites** — избранные сделки, отмеченные пользователем.
- **Фильтры и поиск**:
  - **Фильтр периодов**: All, Today, Yesterday, 3 days, 7 days, 1 month, 3 months.
  - **Режим ⚡ Unique**: показ только уникальных сделок (дедупликация по ID по времени последнего визита).
  - **Поиск**: мгновенный фильтр как по названию сделки, так и по номеру сделки (`#1452590` или `1452590`).
- **Карточка сделки**:
  - Название сделки (ссылка в новой вкладке `target="_blank"`).
  - Мета-строка внизу: номер сделки в выбранном акцентном цвете темы (`color: var(--accent); font-weight: 600;`) и форматированная дата визита («Сегодня, 14:30», «Вчера, 09:15», «DD.MM.YYYY, HH:MM»).
  - **Скрытие действий**: звездочка ★ и корзинка 🗑 скрыты в обычном состоянии и плавно проявляются только при наведении на карточку (`:hover`).
  - **Точечное удаление**: клик по корзинке удаляет строго выбранную запись (остальные визиты этой сделки остаются в сохранности).

## 4. Схема данных (`chrome.storage.local`)

```typescript
interface PipedriveFieldsStorage {
  // Настройки видимости
  [hiddenKey: `hidden:${string}`]: boolean;     // true = скрыто, false/undefined = видимо
  [catalogKey: `catalog:${string}`]: {         // кэш обнаруженных групп и полей
    host: string;
    group: string;
    field?: string;
  };

  // Интерфейс и кастомизация
  'pf-theme': 'dark' | 'light' | 'mono';        // тема оформления
  'pf-accent-color': string;                    // HEX-код акцентного цвета (радужная палитра)
  'pf-sound-enabled': boolean;                  // включен ли звук мяуканья
  'pf_active_view': 'fields' | 'history';       // текущий открытый экран

  // История сделок
  'pf_deal_history': Array<{
    id: string;                                 // ID сделки (например, "1452590")
    title: string;                              // Название сделки
    url: string;                                // Ссылка на сделку в Pipedrive
    timestamp: number;                          // Время визита (Date.now())
  }>;
  'pf_deal_favorites': string[];                // Массив ID избранных сделок
}
```
